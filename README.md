# JobSearch HH: Парсер, фильтрация и работа с файлами

Учебный проект "Поиск вакансий"

## Описание

Этот проект реализует консольное приложение для поиска, фильтрации и сохранения вакансий с платформы [hh.ru](https://hh.ru/) с помощью их API. 
Программа позволяет:
- Получать вакансии по поисковому запросу.
- Сохранять данные о вакансиях в файл (JSON).
- Удобно фильтровать, сортировать, удалять и выводить вакансии.
- Выполнять поиск по ключевым словам и диапазону зарплаты.
- Тестировать все основные функции с помощью pytest.

## Структура проекта

- `src/parser.py` — абстрактный класс для работы с API.
- `src/hh_parser.py` — реализация для hh.ru API.
- `src/vacancy.py` — класс описания вакансии (инкапсуляция, сравнение, валидация).
- `src/file_saver.py` — абстрактный класс для сохранения/чтения вакансий.
- `src/json_saver.py` — сохранение вакансий в JSON.
- `src/utils.py` — функции фильтрации, сортировки, вывода.
- `tests/` — тесты для всех компонентов.

## Запуск

1. Установите зависимости:
```bash
    poetry install  
```
2. Запустите консольное приложение:
```bash
    python main.py
```
3. Следуйте инструкциям в консоли: укажите поисковый запрос, ключевые слова, диапазон зарплаты и количество топ-вакансий.

## Тестирование

В проекте реализованы тесты на `pytest` для всех ключевых функций:
```bash
    pytest
```
Рекомендуется запускать тесты в изолированной среде (например, venv).

## Пример использования

```python
from src.hh_parser import HeadHunterParser
from src.vacancy import Vacancy
from src.json_saver import JSONSaver

hh_api = HeadHunterParser()
json_saver = JSONSaver()

vacancies_json = hh_api.load_vacancies("Python")
vacancies = Vacancy.cast_to_object_list(vacancies_json)
for vacancy in vacancies:
    json_saver.add_vacancy(vacancy)
top_vacancies = json_saver.get_vacancies(salary_min=100000, keyword="Python")
print(top_vacancies)
```

## SOLID и ООП

- Явное разделение абстракций для API и работы с файлами.
- Класс вакансии реализует инкапсуляцию и методы сравнения.
- Классы легко расширяются для новых платформ или форматов файлов.

## Формат файлов

- Все вакансии сохраняются в файле `data/vacancies.json` (создаётся автоматически).
- При необходимости можно реализовать хранение в других форматах (CSV/Excel/TXT).
